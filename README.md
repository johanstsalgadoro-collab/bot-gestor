# GameMonitor Bot

Aplicación web educativa para monitorear el estado de videojuegos en línea con datos simulados.

## Ejecutar localmente

Por usar módulos JavaScript ES6, se recomienda abrir el proyecto mediante un servidor local, por ejemplo Live Server de Visual Studio Code.

## Publicar en GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir el contenido de esta carpeta a la raíz del repositorio.
3. Ir a **Settings > Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama `main` y la carpeta `/ (root)`.
6. Guardar los cambios.

No requiere backend ni instalación de dependencias.
